技术分析不是"看个指标就买卖"，而是一套**从大到小、从宏观到微观、多维度交叉验证**的决策流程。

## 一、先立根基：技术分析的三大前提

所有技术分析都建立在这三个假设上，不承认它们就别用技术分析：

|前提|含义|大白话|
|---|---|---|
|**市场行为包容一切**|价格已经反映了所有信息（基本面、消息面、情绪面）|别管为什么涨，涨了就是有人买|
|**价格以趋势方式演变**|趋势一旦形成，倾向于延续，直到反转信号出现|上涨的会继续涨，下跌的会继续跌|
|**历史会重演**|人性不变，相同的图形会引发相同的反应|太阳底下没有新鲜事|

## 二、分析顺序：从大到小，自上而下

**绝对不能一上来就看日线MACD金叉！** 正确的顺序是：

```
宏观趋势 → 板块趋势 → 个股趋势 → 周期切换 → 买卖点
  (月线)     (周线)     (日线)    (60分钟)   (15/5分钟)
```

| 层级         | 看什么         | 作用                |
| ---------- | ----------- | ----------------- |
| **月线/季线**  | 大趋势方向、牛熊周期  | 决定能不能做（熊市空仓，牛市满仓） |
| **周线**     | 中期趋势、重要支撑压力 | 决定做哪个方向（做多还是做空）   |
| **日线**     | 短期趋势、形态、量价  | 决定选什么股（找形态好的）     |
| **60分钟**   | 波段节奏、背离     | 决定什么时候进（找精确买点）    |
| **5/15分钟** | 超短线、盘口      | 决定具体成交价（抠买卖价位）    |

> **核心原则**：大周期定方向，小周期找买点。大周期向下，小周期的所有"金叉"都是反弹逃命机会；大周期向上，小周期的"死叉"都是加仓机会。

## 三、五大核心分析维度

拿到一只股票，按这个顺序逐项检查：

### 维度1：趋势（最重要）

- **均线系统**：5/10/20/30/60/120/250日均线的排列状态
    - 多头排列（短期在上，长期在下，发散向上）→ 强势
    - 空头排列（短期在下，长期在上，发散向下）→ 弱势
    - 粘合缠绕 → 变盘前夜
- **趋势线**：连接高点的下降趋势线、连接低点的上升趋势线
- **判断**：当前是上涨趋势、下跌趋势、还是横盘震荡？

### 维度2：量价关系（最真实）

量在价先，成交量是资金的脚印，骗不了人：

|量价组合|含义|
|---|---|
|价涨量增|健康上涨，资金进场|
|价涨量缩|上涨乏力，背离预警|
|价跌量增|恐慌抛售，或主力出货|
|价跌量缩|下跌动能衰竭，接近底部|
|横盘放量|筹码交换，可能在吸筹或出货|
|横盘缩量|多空均衡，等待方向选择|

### 维度3：形态（最直观）

- **反转形态**：头肩顶/底、双顶/双底（M头/W底）、圆弧顶/底、V形反转
- **整理形态**：三角形、楔形、旗形、矩形、菱形
- **判断**：当前形态是中继（继续原趋势）还是反转（趋势改变）？

### 维度4：位置（最容易被忽略）

同样的图形，出现在不同位置，含义完全相反：

- **高位放量长阳** → 可能是拉高出货
- **低位放量长阳** → 可能是主力建仓启动
- **高位缩量横盘** → 没人接盘，危险
- **低位缩量横盘** → 抛压穷尽，安全

> **位置判断参考**：看股价在历史区间的百分位（近1年/3年高点到低点的位置），以及距离重要均线（60日/120日/250日）的远近。

### 维度5：指标（辅助验证，不能单独用）

指标是价格的衍生品，永远滞后于价格，只能用来**确认**，不能用来**预测**：

|指标类型|代表指标|用途|
|---|---|---|
|趋势类|MA均线、MACD、BOLL布林带|判断趋势方向和强度|
|震荡类|KDJ、RSI、WR威廉|判断超买超卖、背离|
|量能类|VOL、OBV、量比、换手率|判断资金真实意图|
|压力支撑|筹码分布、黄金分割、缺口|找关键价位|

> **铁律**：指标永远是"事后诸葛亮"。MACD金叉时股价已经涨了一段，KDJ超卖时股价可能还在跌。不要用单一指标做决策，至少2-3个不同维度的指标共振才可靠。

## 四、实战分析的标准流程（拿到一只票，按这个走）

```
第1步：看大周期（月线/周线）
  → 这只票现在是牛是熊？大方向向上还是向下？
  → 距离历史高点/低点有多远？

第2步：看趋势（日线均线）
  → 均线是多头排列还是空头排列？
  → 股价在60日线上方还是下方？

第3步：看量价
  → 最近的上涨/下跌有没有成交量配合？
  → 有没有量价背离？

第4步：看形态
  → 当前在走什么形态？（整理 or 反转）
  → 有没有形成关键形态的突破/破位？

第5步：看位置
  → 股价在高位、中位还是低位？
  → 上方有没有密集套牢盘？下方有没有强支撑？

第6步：指标验证
  → MACD/KDJ/RSI有没有共振信号？
  → 有没有顶背离/底背离？

第7步：制定计划
  → 如果符合条件，买点在哪？止损位在哪？目标位在哪？
  → 如果不符合，放弃，等下一只
```

## 五、技术分析的常见误区（避坑指南）

|误区|正确做法|
|---|---|
|❌ 只看一个指标就买卖|✅ 多维度交叉验证，至少趋势+量价+形态三者共振|
|❌ 小周期定大方向|✅ 大周期定方向，小周期找买点，顺大逆小|
|❌ 指标金叉就买，死叉就卖|✅ 指标是确认工具，不是预测工具，看位置和趋势|
|❌ 忽略成交量|✅ 量在价先，没有量的突破都是假突破|
|❌ 只看图形不看位置|✅ 同样的图形，高位和低位含义完全相反|
|❌ 预测顶部和底部|✅ 不猜顶底，等信号确认，右侧交易|
|❌ 没有止损计划|✅ 买入前先想好止损位，错了就认，不扛单|
|❌ 过度拟合，参数调来调去|✅ 简单的就是最好的，经典参数（5/10/20/60）经过市场检验|

## 六、一句话总结技术分析的核心思路

> **大周期定方向，量能定真假，形态定节奏，位置定安全，指标定细节，止损定生死。**

技术分析本质上是**概率游戏**，没有100%准确的信号。你要做的不是找"必胜战法"，而是建立一套**正期望的交易系统**：亏的时候少亏（止损），赚的时候多赚（让利润奔跑），长期下来稳定盈利。
